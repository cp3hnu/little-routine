# 小小作息 / Little Routine

陪孩子养成健康作息的家庭打卡应用。记录起床与睡觉时间，查看月度统计与 AI 建议，并在目标时间前提醒。

## 核心功能

### 起床 / 睡觉打卡

- 按当前时段一键打卡（起床或睡觉）
- 支持补卡，可手动选择时间
- 多小孩家庭可切换孩子分别记录

### 小孩与目标作息

- 添加、编辑、删除小孩档案
- 为每位小孩设置目标起床时间与目标睡觉时间
- 以家庭为单位管理数据

### 月度统计与报告

- 月历查看每日起床 / 睡觉记录是否齐全
- 展示打卡天数、早起率、早睡率、最长连续天数等指标
- 月末自动生成 AI 月度报告（概况、建议、鼓励语），可按需重新生成
- 报告基于真实打卡数据汇总，不会虚构记录

### 推送提醒

- 可开启 Web 推送，在目标起床 / 睡觉前提醒
- 可配置提前提醒分钟数
- 支持安装到手机主屏作为 PWA 使用

### 账号与偏好

- 手机号 + 密码注册 / 登录
- 中英文界面切换
- 浅色 / 深色 / 跟随系统主题
